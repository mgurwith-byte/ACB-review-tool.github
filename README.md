# UK Anticholinergic Review Tool

This is a static GitHub Pages website.

## Upload these files to your repository root
- index.html
- medication-library.json
- .nojekyll
- README.md

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the files above.
3. Open Settings > Pages.
4. Choose the `main` branch and `/ (root)`.
5. Save and wait for the live URL.

## Notes
- This is a browser-only static site.
- The medication library file must stay in the same folder as index.html.
- Any output should be reviewed by the user against the source medication record and current guidance.
