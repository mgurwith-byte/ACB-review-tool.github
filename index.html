Cognitive Risk Dashboard v2
Multiple datasets, UK product breadth, evidence badges
Version 2

Wider UK medication recognition with evidence badges for ACB, AEC, Beers, and local review rules.

This version loads several JSON datasets, reconciles them into a single review view, and displays evidence badges so users can see whether a flag arises from anticholinergic burden scoring, cognition-oriented AEC scoring, Beers caution criteria, or a configurable local rule.

More UK medicines
Includes more generic names, common brands, and selected combination products such as co-codamol and MST-related aliases.
Evidence badges
Separate badges show source provenance clearly at medicine level.
Modular JSON files
Each dataset can be updated without rewriting the interface.

Medication list

Paste one medicine per line, or use commas or semicolons.

Mandatory review notice: Any output from this dashboard should be reviewed by the user against the medication record, dose, formulation, duration, indication, co-prescribing, co-morbidity, frailty, delirium risk, and current local or national guidance before use in practice.

Source framing

  1. ACB identifies anticholinergic burden scores.
  2. AEC adds a cognition-focused anticholinergic scale.
  3. Beers contributes broader caution labels for delirium and cognition risk.
  4. Local rules let you maintain supplementary UK review prompts and product mappings.
