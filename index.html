UK Anticholinergic & STOPP/START v3 Review Tool
ACB / AEC / Beers / local rules + STOPP/START v3 prompts, GitHub Pages ready
Version 3

Analyse medication lists, export a report, and use a larger structured UK medicine dictionary.

This version stores the medicine library as structured data inside the app, adds CSV report download, improves result transparency, and keeps the whole project as a single static site suitable for GitHub Pages.

Structured dictionary
Each medicine entry stores name, aliases, score label, numeric score, flags, and references separately so the site can scale more cleanly.
CSV export
Download the analysed medication list and summary directly from the browser without a server.
Review first
Unrecognised entries and spelling suggestions remain explicit, and no guessed medicine is scored automatically.

Medication list

Paste one medicine per line, or a list separated by commas or semicolons.

Mandatory review notice: Any output from this website should be reviewed by the user against the clinical record, indication, dose, formulation, duration, frailty, co-morbidity, and current local or national guidance before use in practice.

Interpretation

Run the calculator to view burden totals, class flags, and unresolved medicines.

STOPP/START v3 prompts

Tag-based prompts from the 190 v3 criteria. Always confirm against the patient's full clinical picture (indication, dose, comorbidity, frailty).

Sources used

Structured dictionary from the ACB 2012 list, NHS Wales AEC appendix, and rule-based review flags. STOPP/START v3 prompts from O'Mahony et al., Eur Geriatr Med 2023;14(4):625–632.

Export format

The CSV report includes a summary block, one line per analysed medicine, and any triggered STOPP/START v3 prompts.

References

  1. ACB Scale 2012 update, Aging Brain Care / Indiana University.
  2. PrescQIPP Bulletin 253, anticholinergic burden review guidance.
  3. NHS Wales AEC appendix, 2022-23 appendix with AEC 0-3 examples.
  4. NICE NG97, medication review context in dementia care.
  5. Class flags in this tool are review prompts for opioids, benzodiazepines, z-drugs, sedating antidepressants, and antipsychotics, not a separate validated scale.

GitHub Pages

  1. Create a repository and upload index.html and .nojekyll.
  2. In GitHub, open Settings > Pages.
  3. Select the branch or folder containing index.html.
  4. Save and wait for publication.
