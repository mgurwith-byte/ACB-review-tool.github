Cognitive Risk Dashboard v3
Friendlier unmatched wording, STOPP context layer, repository-ready datasets
Version 3

Paste a medication list to review anticholinergic burden, broader cognitive-risk flags, and STOPP-relevant medicines with clearer matching language.

This version uses a three-state output model: matched and flagged, matched with no current flag, or not matched to the current reference set. It is designed to avoid implying that an unmatched medicine is invalid or nonexistent.

Friendlier unmatched wording
Unmatched entries are described as not matched to the current reference set rather than “not recognised”.
STOPP context
STOPP-relevant medicines show criterion summaries and contextual review prompts rather than automatic rule breaches.
Repository-ready JSON
ACB, AEC, local rules, UK products, and STOPP context can all be updated separately.

Medication list

Paste one medicine per line, or use commas or semicolons.

Mandatory review notice: Any output from this dashboard should be reviewed by the user against the medication record, dose, formulation, duration, indication, co-prescribing, co-morbidity, frailty, delirium risk, and current local or national guidance before use in practice.

Interpretation

The tool separates automatic evidence sources into ACB, AEC, local cognitive-risk rules, Beers-style cautions where loaded, and STOPP contextual prompts where matched.

References

ACB-based flags should be linked to the Anticholinergic Cognitive Burden Scale. STOPP-relevant entries should display their source label directly in the results. A medicine that is not matched to the current reference set should be reviewed manually rather than assumed absent or safe.
