UK Anticholinergic Review Tool
Static GitHub Pages build with CSV export
Ready for GitHub Pages

Paste a medication list, calculate burden, and export a CSV review report.

This static site uses a structured internal medication dictionary, recognises some UK brand names, suggests likely corrections for misspellings, and separates burden scoring from broader cognitive-risk review flags.

Structured medicine data
Loaded from a separate JSON file so the library can be expanded later.
CSV report
Downloadable in the browser without a server.
Review prompt
Guesses are not scored automatically.

Medication list

Paste one medicine per line, or separated by commas or semicolons.

Mandatory review notice: Any output from this website should be reviewed by the user against the medication record, dose, formulation, duration, co-morbidity, frailty, and current guidance before use in practice.

Interpretation

Run the calculator to view totals, flags, and unresolved medicines.

References

ACB 2012 list, NHS Wales AEC appendix, PrescQIPP review bulletin, and NICE review context are cited in the interface.

GitHub Pages

Upload index.html, medication-library.json, and .nojekyll to your repository root and publish from main.

References

  1. ACB Scale 2012 update, Aging Brain Care / Indiana University.
  2. PrescQIPP Bulletin 253, anticholinergic burden review guidance.
  3. NHS Wales AEC appendix, 2022-23 appendix with AEC 0-3 examples.
  4. NICE NG97, dementia medication review context.
  5. Class flags in this tool are rule-based review prompts rather than a separate validated scale.

Deploy

  1. Create a GitHub repository.
  2. Upload index.html, medication-library.json, and .nojekyll.
  3. Open Settings > Pages.
  4. Choose main and / (root).
  5. Save and open the published URL.
