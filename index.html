Cognitive Burden Medication Review

Paste a medication list and review medicines that may worsen cognition.

This static tool helps identify medicines that may worsen cognition through anticholinergic effects, sedative effects, or opioid-related sedation. A separate optional tab is available for contextual STOPP review prompts for users who want that extra detail.

Review required:The main output is designed to support a simple cognitive-burden review. Any output must still be interpreted clinically. The optional STOPP tab contains contextual prompts only and is not an automatic prescribing rule engine.
